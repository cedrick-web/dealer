# KOMISIYONERI | Rwanda property, with proof

A trust-first marketplace for buying, renting and selling houses, apartments, land and commercial property across Rwanda, starting in Kigali.

## Stack
- React + TypeScript + Vite frontend
- Dart + Shelf API
- MongoDB
- Docker Compose
- Solidity evidence-hash anchor contract source

## Trust boundary
This platform is not the National Land Authority and does not certify ownership or transfer title. Rwanda's official voluntary-sale workflow requires the land UPI to correspond to the seller and advises checking with the Sector Land Manager if ownership is uncertain: https://support.irembo.gov.rw/en/support/solutions/articles/47001210595-how-to-apply-for-title-transfer-voluntary-sale- .

A hash proves only that bytes match a recorded digest, not that a document is genuine. Never put identity scans, land-title PDFs, chats or personal data on a public blockchain.

## Revenue
Agent SaaS subscriptions; clearly labelled promoted listings; disclosed fixed listing/media/verification coordination fees; success commission under a signed agreement; property-management referrals. Do not hold sale/rent funds without legal review and a properly licensed payment partner.

## Status
This repository is being built in increments. Features must not be described as live until implemented, tested and connected to authorized external services.
